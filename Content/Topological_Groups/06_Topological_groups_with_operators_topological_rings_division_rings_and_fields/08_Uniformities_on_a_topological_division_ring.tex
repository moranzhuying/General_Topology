\section{拓扑除环上的一致结构}

记号约定:$K$是拓扑除环.

\begin{convention}{}{}
	我们需要在$K$中区分如下三种一致结构:
	\begin{itemize}
		\item 加法一致结构:$K$的加法群上的一致结构.
		\item 乘法左一致结构:$K^{\times}$上的左一致结构.
		\item 乘法右一致结构:$K^{\times}$上的右一致结构.
	\end{itemize}
	当$K$是域时,乘法左一致结构和乘法右一致结构统称为乘法一致结构.
\end{convention}

\begin{proposition}{}{}
	设$K$是Hausdorff的.下列陈述等价:
	\begin{enumerate}
		\item $\hat{K}$是拓扑除环.
		\item $K$中每个不以$0$为聚点的加法Cauchy滤子在映射$K^{\times}\to K^{\times},x\mapsto x^{-1}$下的前推还是加法Cauchy滤子.
	\end{enumerate}
\end{proposition}

\begin{proposition}{}{}
	设$K^{\times}$的每个乘法左Cauchy滤子都是乘法右Cauchy滤子.如果$K$的加法一致结构是Hausdorff完备的,那么$K$的乘法一致结构也是Hausdorff完备的.
\end{proposition}

\begin{corollary}{}{}
	设如果$K$的加法一致结构是Hausdorff完备的,那么$K$的乘法一致结构也是Hausdorff完备的.
\end{corollary}
